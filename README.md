# 🎥🎵 英语音视频复述练习评判系统

这是一个基于Gradio的英语学习应用，可以帮助您练习英语听说能力。系统会自动转录音频/视频内容，让您复述，然后使用AI进行严格评判。

## ✨ 主要功能

- 📹🎵 **多媒体文件支持**：支持上传音频和视频文件
  - **音频格式**: MP3, WAV, FLAC, M4A, AAC, OGG, WMA
  - **视频格式**: MP4, AVI, MOV, MKV, WMV, FLV, WebM
- 🎯 **AI转录**：使用OpenAI Whisper模型进行高精度语音转文字
- 🎤 **语音录制**：通过麦克风录制您的复述音频
- 🤖 **智能评判**：使用本地Ollama + Gemma2模型进行100分制严格评判
- 📊 **详细反馈**：提供多维度评分和具体改进建议

## 🛠️ 安装要求

### 1. 系统依赖

#### Windows:
```bash
# 安装FFmpeg（用于视频处理，音频文件可选）
# 下载FFmpeg并将其添加到系统PATH中
# 或使用chocolatey安装
choco install ffmpeg
```

#### macOS:
```bash
# 使用Homebrew安装FFmpeg
brew install ffmpeg
```

#### Linux:
```bash
# Ubuntu/Debian
sudo apt update && sudo apt install ffmpeg

# CentOS/RHEL
sudo yum install ffmpeg
```

### 2. Python依赖
```bash
# 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或
venv\Scripts\activate  # Windows

# 安装Python依赖
pip install -r requirements.txt
```

### 3. Ollama安装与配置

#### 安装Ollama:
- **Windows/Mac/Linux**: 访问 [https://ollama.ai](https://ollama.ai) 下载安装

#### 配置模型:
```bash
# 启动Ollama服务
ollama serve

# 在新终端中下载Gemma2模型
ollama pull gemma2

# 验证模型安装
ollama list
```

## 🚀 使用方法

### 1. 启动应用
```bash
python app.py
```

### 2. 使用流程

1. **上传文件**：
   - 点击"选择音频/视频文件"或直接拖拽文件到上传区域
   - 支持常见的音频格式（MP3、WAV等）和视频格式（MP4、AVI等）
   - 点击"开始处理文件"按钮
   - 等待系统转录成文字

2. **复述练习**：
   - 阅读转录出的原始文本
   - 点击麦克风图标开始录制您的复述
   - 录制完成后点击"转录复述音频"

3. **获取评判**：
   - 确保原始文本和复述文本都已显示
   - 点击"开始评判"按钮
   - 等待AI分析并给出详细评分

## 📝 评判标准

系统采用100分制，从以下维度进行严格评判：

- **内容准确性 (30分)**：复述内容与原文的匹配程度
- **语法正确性 (25分)**：语法结构的准确性
- **词汇使用 (20分)**：词汇选择的准确性和丰富性
- **流利度 (15分)**：语言表达的流畅程度
- **完整性 (10分)**：复述的完整程度

## 🔧 故障排除

### 常见问题：

1. **"无法连接到Ollama服务"**
   ```bash
   # 确保Ollama服务正在运行
   ollama serve
   ```

2. **"音频/视频处理失败"**
   - 对于视频文件：检查FFmpeg是否正确安装
   - 对于音频文件：确认文件格式受支持
   - 检查文件是否损坏

3. **"Whisper模型加载失败"**
   - 检查网络连接（首次运行需要下载模型）
   - 确保有足够的磁盘空间

4. **模型响应慢**
   - Whisper首次运行会下载模型，需要一些时间
   - 音频文件比视频文件处理速度更快
   - Gemma2模型较大，评判过程需要几十秒

### 性能优化：

- **使用GPU加速**：如果有NVIDIA GPU，安装`torch`的CUDA版本可以显著提升处理速度
- **文件格式选择**：
  - **推荐音频格式**：WAV（无损）或MP3（压缩但兼容性好）
  - **推荐视频格式**：MP4（兼容性最好）
- **选择合适的Whisper模型**：代码中使用的是`base`模型，您可以根据需要选择：
  - `tiny`: 最快，准确度较低
  - `base`: 平衡速度和准确度（默认）
  - `small`: 较慢，准确度较高
  - `medium/large`: 最慢，准确度最高

## ⚠️ 注意事项

- 首次运行需要下载Whisper模型，请确保网络连接稳定
- 录制音频时请保持环境安静，以获得最佳转录效果
- 建议使用高质量的音频设备获得更好的复述效果
- **音频文件比视频文件处理速度更快**，推荐使用音频格式
- 文件大小建议在100MB以内，过大文件处理时间较长
- Ollama服务需要较多内存，建议至少8GB RAM

如果遇到问题，请检查：

2. Ollama服务是否正在运行
3. 防火墙是否阻止了相关端口
4. 系统资源是否充足
5. 上传的文件格式是否受支持
